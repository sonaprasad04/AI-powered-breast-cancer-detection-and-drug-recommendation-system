SMARTCARE: AI-Powered Breast Cancer Diagnosis and Drug Recommendation System

About the Project
SMARTCARE is a machine learning-based academic project designed to predict breast cancer and provide potential drug recommendations based on predicted drug response.
The project combines machine learning models with a web application interface.

 Objectives

* Predict breast cancer using a machine learning classification model.
* Estimate drug response using a regression model.
* Integrate machine learning models into a web application.
* Provide a user-friendly interface for submitting input features and viewing predictions.

Technologies Used

* Python
* Machine Learning
* Scikit-learn
* Pandas
* NumPy
* Jupyter Notebook
* FastAPI
* React
* Tailwind CSS

Machine Learning Models

1. Breast Cancer Prediction

A Random Forest Classifier is used to classify breast cancer based on the selected input features.

2. Drug Response Prediction

An ElasticNet Regression model is used to estimate drug response and support the drug recommendation component.

3. Data Preprocessing

Principal Component Analysis (PCA) and feature scaling are explored during data preprocessing.

Project Structure

* `backend/` – Backend API and application logic.
* `frontend/` – Frontend user interface.
* `datasets/` – Datasets used for model development, subject to availability and sharing permissions.
* `cancer_classification.ipynb` – Breast cancer classification experiments.
* `drug_response_prediction.ipynb` – Drug response prediction experiments.
* `final_integration.ipynb` – Model integration experiments.
* `pca.ipynb` – PCA and feature selection experiments.
